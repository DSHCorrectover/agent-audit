# Security Policy

## Supported versions
Latest release on the default branch.

## Reporting a vulnerability
Email **wangguigui@correctover.com**. Please include: environment fingerprint, fixed reproduction vector, and idempotent repro steps. We practice fail-closed disclosure: no reproduction evidence = no finding; findings are published only after coordinated disclosure with the affected project.

## Response targets
- Acknowledgement: 48h
- Triage result: 7d
- Fix or coordinated disclosure plan: 30d

## Scope
All Correctover packages and repos. Out of scope: social engineering, volumetric DoS.
